       - If resulting text is empty, return `["The", "speaker", "is", "saying"]` (LLM scaffolding for empty context per research pitfall 5)

       - Import `wordFrequencyList` from `./data/wordFrequency.json`
       - Import `BIGRAM_INDEX` from `./data/bigrams`
       - Import `LocalPrediction` from `./types`

       - Define `NAME_INTRO_PATTERNS` array of RegExp:
         ```
         /\bmy name is\s*$/i
         /\bi'm\s*$/i
         /\bi am\s*$/i
         /\bname's\s*$/i
         /\bcall me\s*$/i
         /\bi go by\s*$/i
         ```

       - Define `DEMO_SPEAKER_NAME = 'Aadit'` (per D-04)

       - Define confidence scoring function `bigramConfidence(rank: number): number`:
         - rank <= 1: return 0.85
         - rank <= 3: return 0.80
         - rank <= 5: return 0.75
         - rank > 5: return 0.65

       - Export function `predict(contextWords: string[]): LocalPrediction`:
         - Pass 0 (name override per D-04): join contextWords with space, test against each NAME_INTRO_PATTERN. If any matches, return `{ word: DEMO_SPEAKER_NAME, confidence: 1.0 }`
         - Pass 1 (bigram lookup): get last word from contextWords, lowercase. Look up in BIGRAM_INDEX. If found and has entries, take first entry, return `{ word: candidate.word, confidence: bigramConfidence(candidate.rank) }`
         - Pass 2 (unigram fallback): return `{ word: wordFrequencyList[0], confidence: 0.55 }` (most frequent English word)
