<objective>
Build the LLM fallback client, prediction engine orchestrator, and the React hook that wires detection events to predictions. This completes the full prediction pipeline: detection event -> local prediction -> optional LLM upgrade -> predicted word in store.

Purpose: The LLM fallback improves prediction accuracy when the local model is unsure, but is hard-capped at 200ms to stay within the 500ms total latency budget. The pipeline never returns empty — the local prediction is always the safety net. Per D-01, OpenAI API is the LLM provider (not Groq).

Output: Complete prediction pipeline with tests, wired to detection events via usePredictionPipeline hook.
</objective>

    - Request body includes model: "gpt-4o-mini", stream: true, max_tokens: 3, temperature: 0
    - Request headers include Authorization: "Bearer {key}" and Content-Type: "application/json"

    - Respects AbortSignal — throws AbortError when signal is aborted

    Prediction Engine (predictionEngine.test.ts):
    - predict() calls localPredictor.predict() first
    - When local confidence >= 0.7, returns immediately with source "local" — no fetch call
    - When local confidence < 0.7, fires llmClient.predictNextWord with AbortController
    - 200ms timeout on AbortController: if LLM returns in time, source is "llm"
    - If LLM aborts (timeout), returns local prediction with source "local-fallback"
    - If LLM throws (network error), returns local prediction with source "local-fallback"
    - latencyMs is set via performance.now() difference
    - triggeredByEventId is set from StutterEvent.id
    - Duplicate event ID (same as last processed) is ignored — returns null
  </behavior>

         - If `event.id === lastProcessedEventId`, return `null` (duplicate guard)

         - Try: `const word = await predictNextWord(contextWords, controller.signal)`, clearTimeout, return with source 'llm'
         - Catch: clearTimeout, return `{ word: local.word, source: 'local-fallback', latencyMs: performance.now() - t0, triggeredByEventId: event.id }`
       - Export function `resetEngine(): void` — sets `lastProcessedEventId = null` (for testing)
