**1. Create `pi-daf/bt_connect_loop.py`** — BT retry-forever module (per D-04).

```python
# bt_connect_loop.py — Retry BT connection forever until headphones connect
```

- Function `wait_for_connection(mac: str, interval: int = 10) -> None`:
  - Loops forever (while True)
  - Each iteration: call `check_bt_status(mac)` from `audio.bt_setup`
  - If `status["connected"]` is True, print success message and return
  - If not connected, call `connect_device(mac)` — if returns True, return
  - If still not connected, print `[bt_connect_loop] Beat Buds not found. Retrying in {interval}s...` and `time.sleep(interval)`
  - Catch all exceptions inside the loop body (print warning, continue) so a transient bluetoothctl error never kills the retry
- Function `ensure_trusted(mac: str) -> None`:
  - Run `subprocess.run(["bluetoothctl", "trust", mac])` — ensures auto-reconnect after pairing (idempotent)
- Log all actions with `[bt_connect_loop]` prefix for journald visibility

**2. Create `pi-daf/fluent-daf.service`** — systemd user service unit (per D-03).

```ini
[Unit]
Description=Fluent DAF — Delayed Auditory Feedback for stuttering
After=bluetooth.target pipewire.service
Wants=pipewire.service

[Service]
Type=simple
ExecStart=/usr/bin/python3 /home/pi/Fluent/pi-daf/main.py --auto
Restart=always
RestartSec=5
Environment=PYTHONUNBUFFERED=1
WorkingDirectory=/home/pi/Fluent/pi-daf

[Install]
WantedBy=default.target
```

Key choices:
- `Restart=always` + `RestartSec=5` — if Beat Buds disconnect mid-session (PortAudioError), service restarts and the BT retry loop in main.py reconnects
- `PYTHONUNBUFFERED=1` so all prints appear in journald immediately
- `After=bluetooth.target pipewire.service` — wait for BT and audio stack
- User service (not system) because PipeWire runs as user — installed via `systemctl --user`
- Path uses `/home/pi/Fluent/pi-daf/` — the install script will sed-replace this with the actual path

**3. Create `pi-daf/install-service.sh`** — one-command installer.

```bash
#!/usr/bin/env bash
set -euo pipefail
```

Steps:
- Detect the actual project path: `SCRIPT_DIR="$(cd "$(dirname "$0")" && pwd)"`
- Read the Beat Buds MAC from first argument or prompt: `MAC="${1:?Usage: bash install-service.sh AA:BB:CC:DD:EE:FF}"`
- Create `~/.config/systemd/user/` if it doesn't exist
- Copy `fluent-daf.service` to `~/.config/systemd/user/fluent-daf.service`
- sed-replace `/home/pi/Fluent/pi-daf` with `$SCRIPT_DIR` in the installed service file
- sed-replace the ExecStart line to append `--mac $MAC` so the MAC address is baked into the service
- Run `systemctl --user daemon-reload`
- Run `systemctl --user enable fluent-daf.service`
- Run `sudo loginctl enable-linger $USER` (so user services survive logout — already in setup.sh but repeated for safety)
- Print success message with: "Service installed. It will start automatically on next boot."
- Print: "To start now: systemctl --user start fluent-daf.service"
- Print: "To view logs: journalctl --user -u fluent-daf.service -f"
