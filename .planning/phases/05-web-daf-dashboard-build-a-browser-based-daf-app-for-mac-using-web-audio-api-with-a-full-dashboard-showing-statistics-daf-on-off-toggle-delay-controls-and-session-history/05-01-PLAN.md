**1. Create `src/audio/dafEngine.ts`** -- a factory function that creates a DAF audio path using Web Audio API DelayNode.

```typescript
export interface DAFEngine {
  enable: () => void;      // Connect delay path to destination
  disable: () => void;     // Disconnect delay path (silence output)
  setDelay: (ms: number) => void;  // Set delay in ms (10-100), per D-03
  isEnabled: () => boolean;
  destroy: () => void;     // Clean up nodes
}

export function createDAFEngine(
  audioCtx: AudioContext,
  source: MediaStreamAudioSourceNode
): DAFEngine;
```

Implementation details:
- Create a `DelayNode` from the existing `AudioContext` (do NOT create a new AudioContext -- reuse the one from acousticAnalyzer).
- Set `delayNode.delayTime.value` to convert ms to seconds (e.g., 50ms = 0.05s).
- Audio graph: `source -> delayNode -> audioCtx.destination` (when enabled).
- When disabled, disconnect `delayNode` from `audioCtx.destination` so no audio plays back.
- `setDelay(ms)` clamps to 10-100 range per D-03, then sets `delayNode.delayTime.value = ms / 1000`. Use `setValueAtTime` for glitch-free changes.
- `enable()`/`disable()` toggle the connection to destination.
- The `source` node is shared with the AnalyserNode -- both connect to the same source (fan-out from MediaStreamAudioSourceNode is supported by Web Audio API).
- Set DelayNode `maxDelay` to 0.2 (200ms) to allow headroom above the 100ms slider max.
