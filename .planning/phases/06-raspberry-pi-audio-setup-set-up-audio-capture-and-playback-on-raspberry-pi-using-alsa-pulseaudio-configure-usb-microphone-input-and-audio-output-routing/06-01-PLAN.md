  <action>
    Create the pi-daf/ project directory structure per the research architecture pattern.

    **pi-daf/setup.sh** (per D-07, D-08 — Pi OS Lite, PipeWire audio framework):
    A bash script to be run once on a fresh Raspberry Pi OS Lite (Bookworm). Must:
    1. `sudo apt update`
    2. `sudo apt install -y bluez pipewire pipewire-audio pipewire-pulse wireplumber libspa-0.2-bluetooth python3-pip python3-numpy portaudio19-dev`
    3. `pip3 install sounddevice numpy` (numpy may already be installed via apt but pip ensures latest)
    4. `sudo loginctl enable-linger $USER` (per Pitfall 2 — PipeWire user services must survive SSH logout)
    5. `systemctl --user enable --now pipewire pipewire-pulse wireplumber`
    6. Create WirePlumber HFP override at `~/.config/wireplumber/wireplumber.conf.d/51-bluez-config.conf` with content (per Pattern 2 from research, per D-02/D-03 — Beat Buds HFP):
       ```
       monitor.bluez.properties = {
         bluez5.roles = [ hsp_hs hsp_ag hfp_hf hfp_ag a2dp_sink a2dp_source ]
         bluez5.hfphsp-backend = "native"
         bluez5.auto-connect = [ hfp_hf hsp_hs a2dp_sink ]
       }
       ```
    7. `systemctl --user restart wireplumber`
    8. Print a success message with next steps (pair headphones)

    Make the script idempotent (safe to run multiple times). Add `set -euo pipefail` at the top. Mark executable with `chmod +x`.

    **pi-daf/config.py** (per D-03/D-08 — HFP 8kHz mono, flexible delay):
    ```python
    SAMPLE_RATE = 8000        # HFP CVSD default; change to 16000 if mSBC negotiated
    CHANNELS = 1              # HFP is mono
    BLOCK_SIZE = 256          # ~32ms at 8kHz — balance between latency and stability
    DELAY_MS = 50             # DAF therapeutic target (research: 50-75ms optimal)
    DEVICE_NAME_HINT = "bluez" # Substring to match BT device in sounddevice
    ```

    **pi-daf/audio/__init__.py**: Empty file (package marker).

    **pi-daf/audio/device_utils.py** (per Pattern 4 from research):
    Create module with two functions:
    1. `find_bt_device(partial_name: str) -> int | None` — iterates `sd.query_devices()`, returns index of first device whose name contains `partial_name` (case-insensitive). Returns None if not found.
    2. `list_all_devices() -> None` — prints all devices from `sd.query_devices()` formatted nicely, plus `sd.default.device` info. This is a diagnostic helper.
    3. A `if __name__ == "__main__":` block that calls `list_all_devices()` so you can run `python3 -m audio.device_utils` as a quick diagnostic.

    **pi-daf/.gitignore**:
    ```
    __pycache__/
    *.pyc
    .venv/
    *.egg-info/
    ```
