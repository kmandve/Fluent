  <action>
    Create three files that complete the pi-daf Python application.

    **pi-daf/audio/bt_setup.py** (per D-02 — Beat Buds, per Pattern 1 from research):
    A helper module for Bluetooth pairing. Since pairing is interactive (requires the user to put headphones in pairing mode), this module provides:
    1. `check_bt_status(mac: str) -> dict` — runs `bluetoothctl info <mac>` via subprocess, parses output, returns dict with keys: `paired` (bool), `trusted` (bool), `connected` (bool), `name` (str or None). Returns all-False dict if device not found.
    2. `print_pairing_instructions(mac: str) -> None` — prints step-by-step bluetoothctl commands the user needs to run for first-time pairing (power on, agent on, scan on, pair, trust, connect). Include the MAC address in each command. Reference Pattern 1 from research.
    3. `connect_device(mac: str) -> bool` — runs `bluetoothctl connect <mac>` via subprocess, returns True if "Connection successful" appears in output, False otherwise. This is for reconnection after initial pairing.
    4. A `if __name__ == "__main__":` block that takes an optional MAC argument from sys.argv and calls check_bt_status + prints result, or prints_pairing_instructions if not connected.

    Use `subprocess.run()` with `capture_output=True, text=True, timeout=15` for all bluetoothctl calls. Handle subprocess.TimeoutExpired gracefully.

    **pi-daf/audio/daf_engine.py** (per D-03/D-08, per Pattern 3 from research):
    The core DAF loop. Must:
    1. Import from config: SAMPLE_RATE, CHANNELS, BLOCK_SIZE, DELAY_MS
    2. Calculate DELAY_BLOCKS = max(1, int((SAMPLE_RATE * DELAY_MS / 1000) / BLOCK_SIZE))
    3. Create a `collections.deque(maxlen=DELAY_BLOCKS + 2)` ring buffer, pre-filled with silence (numpy zeros)
    4. Define `audio_callback(indata, outdata, frames, time, status)`:
       - If status has input_overflow or output_underflow, print a warning (but ONLY print outside the callback via a flag — do NOT call print() inside the callback per anti-pattern guidance). Actually, for hackathon simplicity: set a module-level `_last_status` variable and check it in the main loop. But for the callback itself, just do the deque operations.
       - `ring_buffer.append(indata.copy())`
       - `outdata[:] = ring_buffer[0]` (oldest chunk = delayed audio)
    5. Define `start_daf(device_index: int | None = None) -> None`:
       - Opens `sd.Stream` with device=(device_index, device_index), samplerate=SAMPLE_RATE, channels=CHANNELS, blocksize=BLOCK_SIZE, dtype='float32', latency='low', callback=audio_callback
       - Prints "DAF running (delay={DELAY_MS}ms, rate={SAMPLE_RATE}Hz, block={BLOCK_SIZE}) — Ctrl+C to stop"
       - Blocks on `threading.Event().wait()` inside the `with` block
       - Catches KeyboardInterrupt to exit cleanly
       - Prints "DAF stopped." on exit

    Keep the callback function minimal — only deque append and array copy. No allocations, no print, no I/O.

    **pi-daf/main.py** (entry point per research architecture):
    1. Import from audio.device_utils: find_bt_device, list_all_devices
    2. Import from audio.daf_engine: start_daf
    3. Import from audio.bt_setup: check_bt_status, print_pairing_instructions, connect_device
    4. Import from config: DEVICE_NAME_HINT
    5. Accept optional CLI args: `--mac MAC_ADDRESS` (for BT operations), `--list-devices` (diagnostic), `--delay N` (override DELAY_MS)
    6. Use argparse for argument parsing
    7. If `--list-devices`: call list_all_devices() and exit
    8. If `--mac` provided: check_bt_status, if not connected try connect_device, if still not connected print_pairing_instructions and exit
    9. Find BT device: `device_idx = find_bt_device(DEVICE_NAME_HINT)`
    10. If device_idx is None: print error with diagnostic suggestions (run --list-devices, check BT connection), exit 1
    11. If `--delay` provided: monkey-patch config.DELAY_MS before starting (or pass as argument)
    12. Call start_daf(device_idx)
    13. `if __name__ == "__main__":` guard

    Print clear status messages at each step so the user can see what's happening.
