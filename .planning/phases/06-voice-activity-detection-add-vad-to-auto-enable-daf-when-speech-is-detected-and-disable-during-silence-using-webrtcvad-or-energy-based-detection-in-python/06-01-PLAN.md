<objective>
Add energy-based Voice Activity Detection to the DAF engine so delayed playback only engages when the user is speaking. When speech stops, DAF stays active for a 2-second hangover period before muting — preventing annoying on/off flicker during natural pauses. A subtle audio cue (short sine tone) signals state changes.

Purpose: Continuous DAF during silence is distracting and fatiguing. Speech-gating makes the DAF feel natural — it activates when needed and disappears when not.

Output: Modified daf_engine.py with VAD-gated output, config.py with VAD constants, main.py with --vad-threshold flag.
</objective>

```python
VAD_CUE_VOLUME = 0.08       # Volume of the cue tone (subtle — per D-03)
```

**daf_engine.py** — Modify to add speech-gated DAF:

1. Import the new VAD constants: `VAD_RMS_THRESHOLD, VAD_HANGOVER_MS, VAD_CUE_FREQ_ON, VAD_CUE_FREQ_OFF, VAD_CUE_DURATION_MS, VAD_CUE_VOLUME`

2. Add module-level VAD state variables (mutable, accessed only from audio callback thread — no lock needed since sounddevice callbacks are serialized):
```python
# VAD state — modified only inside audio_callback (single-threaded by sounddevice)
_vad_active: bool = False           # True when speech detected (DAF output enabled)
_vad_hangover_blocks: int = 0       # Countdown blocks remaining before deactivating
_vad_cue_samples_remaining: int = 0 # Samples left to play of the cue tone
_vad_cue_phase: float = 0.0         # Phase accumulator for cue sine wave
_vad_cue_freq: float = 0.0          # Current cue frequency (on or off)

# Pre-compute hangover in blocks
VAD_HANGOVER_BLOCKS = max(1, int((SAMPLE_RATE * VAD_HANGOVER_MS / 1000) / BLOCK_SIZE))
VAD_CUE_SAMPLES = int(SAMPLE_RATE * VAD_CUE_DURATION_MS / 1000)
```

3. Modify `audio_callback` to implement speech gating (per D-01):
   - Compute RMS of `indata`: `rms = float(np.sqrt(np.mean(indata ** 2)))`
   - If `rms >= VAD_RMS_THRESHOLD` (using the effective threshold, see start_daf changes):
     - Set `_vad_active = True`, reset `_vad_hangover_blocks = VAD_HANGOVER_BLOCKS`
     - If was previously inactive, trigger activation cue (set `_vad_cue_samples_remaining = VAD_CUE_SAMPLES`, `_vad_cue_freq = VAD_CUE_FREQ_ON`)
   - Else (silence):
     - If `_vad_hangover_blocks > 0`: decrement by 1, keep `_vad_active = True` (per D-02 — hangover)
     - Else if `_vad_active`: deactivate — set `_vad_active = False`, trigger deactivation cue (`_vad_cue_freq = VAD_CUE_FREQ_OFF`)
   - Output decision:
     - If `_vad_active`: `outdata[:] = ring_buffer[0]` (normal DAF)
     - Else: `outdata[:] = 0.0` (silence — DAF muted)
   - Audio cue overlay (per D-03): if `_vad_cue_samples_remaining > 0`, generate sine wave samples and ADD them to outdata (don't replace). Use `_vad_cue_phase` as a phase accumulator for continuity across blocks. Decrement `_vad_cue_samples_remaining` by the number of samples generated.
   - Always push `indata.copy()` to ring_buffer regardless of VAD state (so delayed audio is ready when speech resumes).

4. Modify `start_daf` signature to accept `vad_threshold: float | None = None`:
   - Store effective threshold in a module-level variable `_effective_vad_threshold` that `audio_callback` reads.
   - Reset all VAD state variables in `start_daf` (same pattern as ring_buffer reset).
   - Print VAD config: `"[daf_engine] VAD enabled — threshold={threshold}, hangover={VAD_HANGOVER_MS}ms"`

IMPORTANT constraints for audio_callback:
- RMS computation (`np.sqrt(np.mean(indata ** 2))`) is O(BLOCK_SIZE) — fast enough for real-time.
- Sine wave generation for cue uses `np.arange` + `np.sin` — pre-computed per block, no per-sample Python loop.
- No I/O (print, logging) inside the callback. Only set `_last_status` for main thread to report.
- Use `global` declarations for all module-level VAD state variables modified in the callback.
