    1. Run `npm run dev` and open Chrome at localhost
    2. Click Start — microphone should activate, transcript should appear as you speak
    3. **Test silent block (STUT-01, STUT-04):** Speak a partial sentence, then deliberately stop mid-word and hold silence for 1-2 seconds. Watch the Detection Log — a "block" event should appear within ~400-500ms of the silence onset. Transcript area should briefly pulse with an amber highlight.
    4. **Test repetition (STUT-02):** Try saying "b-b-b-book" or "the the the cat." Check if a "repetition" event appears in the log. (Note: Chrome ASR may collapse repeated syllables — if no repetition event fires, this is acceptable per D-05.)

    7. **Test cooldown:** If a block event fires, verify no second event fires within 1.5 seconds even if you remain silent.
    8. **Check console:** Open DevTools console. You should see `[useAudioPipeline] Ambient calibration complete, threshold: X.XXX` within 3 seconds of starting.
    9. **Visual check:** The Detection Log panel should look clean, small, and not dominate the UI. Type badges should be colored (red for block, amber for repetition, blue for prolongation).
