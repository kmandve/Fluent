  <behavior>
    - FSM starts in FLUENT state
    - tick() with energyLevel=0.005 (below threshold) and stalled interimText for 400ms transitions FLUENT -> ONSET_SILENCE -> fires block event
    - tick() with energyLevel=0.005 for only 200ms stays in ONSET_SILENCE, no event
    - tick() with energyLevel=0.005 then energy jumps back above threshold resets to FLUENT, no event
    - tick() in COOLDOWN state with now < cooldownUntilMs returns no event
    - tick() in COOLDOWN state with now >= cooldownUntilMs transitions back to FLUENT
    - tick() with interimText ending in "um" does NOT fire block even if energy is low
    - tick() with interimText="" and lastInterimText="" does NOT enter ONSET_SILENCE (empty-to-empty guard)
    - tick() detects repetition when detectRepetition returns detected: true and confidence >= 0.72
    - tick() detects prolongation when detectProlongation returns detected: true and confidence >= 0.72
    - After any confirmed detection, cooldown prevents new events for 1500ms
    - Block confidence computation: higher for longer silence duration and lower energy
    - calibrateAmbientNoise collects samples for 2500ms and returns p95 * 1.5
  </behavior>
  <action>
    1. Create `src/detection/stutterDetector.ts`:

       Export threshold constants:
       ```typescript
       export const BLOCK_ENERGY_THRESHOLD_DEFAULT = 0.015;
       export const BLOCK_CONFIRM_MS = 400;
       export const TRANSCRIPT_STALL_MS = 200;
       export const CONFIDENCE_THRESHOLD = 0.72;
       export const COOLDOWN_MS = 1500;
       export const CALIBRATION_DURATION_MS = 2500;
       export const CALIBRATION_SAMPLE_INTERVAL_MS = 100;
       ```

       Export `calibrateAmbientNoise(getRMS: () => number, durationMs?: number, sampleIntervalMs?: number): Promise<number>`:
       - Collect RMS samples every sampleIntervalMs for durationMs
       - Sort samples, take 95th percentile, multiply by 1.5
       - Return computed threshold (minimum of result and BLOCK_ENERGY_THRESHOLD_DEFAULT to avoid overly permissive thresholds)

       Export `createStutterDetector(options?: { blockEnergyThreshold?: number })` factory:
       - Internal state: DetectorContext initialized to FLUENT, silenceStartMs=null, lastInterimText='', lastInterimChangeMs=Date.now(), cooldownUntilMs=0
       - `blockEnergyThreshold` defaults to BLOCK_ENERGY_THRESHOLD_DEFAULT, can be set via options or via `setThreshold(t: number)` method

       The factory returns an object with:
       - `tick(energyLevel: number, interimText: string, now: number): StutterEvent | null`
       - `getState(): DetectorState` (for debugging/testing)
       - `setThreshold(threshold: number): void`
       - `reset(): void`

       `tick()` logic:
       a. Update lastInterimText tracking: if interimText !== ctx.lastInterimText, update lastInterimText and lastInterimChangeMs to now
       b. If now < cooldownUntilMs, return null (stay in COOLDOWN)
       c. If state is COOLDOWN and now >= cooldownUntilMs, transition to FLUENT, return null
       d. Check repetition: call detectRepetition(interimText). If detected and confidence >= CONFIDENCE_THRESHOLD, fire repetition event, enter COOLDOWN for COOLDOWN_MS, return event
       e. Check prolongation: call detectProlongation(energyLevel, interimText, ctx.lastInterimText, ctx.lastInterimChangeMs, now). If detected and confidence >= CONFIDENCE_THRESHOLD, fire prolongation event, enter COOLDOWN, return event
       f. Block detection FSM:
          - Guard: if endsWithFiller(interimText), stay FLUENT, return null
          - Guard: if interimText is '' and lastInterimText is '' (empty-to-empty), stay FLUENT, return null (prevents false triggers on recognition restart — per Pitfall 3)
          - FLUENT: if energy < blockEnergyThreshold AND (now - lastInterimChangeMs) > TRANSCRIPT_STALL_MS, transition to ONSET_SILENCE, set silenceStartMs = now
          - ONSET_SILENCE: if energy >= blockEnergyThreshold, transition back to FLUENT (noise spike reset). If silenceStartMs exists and (now - silenceStartMs) >= BLOCK_CONFIRM_MS, compute block confidence = min(0.95, 0.60 + ((now - silenceStartMs) / 2000) * 0.2 + (1 - energyLevel / blockEnergyThreshold) * 0.15). If confidence >= CONFIDENCE_THRESHOLD, fire block event with silenceDurationMs, enter COOLDOWN, transition to FLUENT via cooldown
          - BLOCK_CONFIRMED: immediately enter COOLDOWN (should not linger here)

       When firing an event, call `useSessionStore.getState().addDetectionEvent(event)` where event has `id: crypto.randomUUID()`.

         b. "block detection: does NOT fire at 200ms (below BLOCK_CONFIRM_MS)"
         c. "block detection: resets to FLUENT when energy rises during ONSET_SILENCE"
         d. "block detection: suppressed when interimText ends with filler word"
         e. "block detection: suppressed on empty-to-empty transcript (recognition restart)"
         f. "cooldown: no events fire during 1500ms cooldown window"
