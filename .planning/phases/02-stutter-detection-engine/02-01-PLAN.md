  <action>
    1. Create `src/detection/types.ts`:
       ```typescript
       export type StutterType = 'block' | 'repetition' | 'prolongation';
       export type DetectorState = 'FLUENT' | 'ONSET_SILENCE' | 'BLOCK_CONFIRMED' | 'COOLDOWN';

       export interface StutterEvent {
         id: string;
         type: StutterType;
         confidence: number;
         timestamp: number;
         silenceDurationMs?: number;
         repeatCount?: number;
         stallDurationMs?: number;
       }

       export interface DetectorContext {
         state: DetectorState;
         silenceStartMs: number | null;
         lastInterimText: string;
         lastInterimChangeMs: number;
         cooldownUntilMs: number;
       }
       ```

    2. Create `src/detection/fillerWords.ts`:
       - Export `FILLER_WORDS` as a `Set<string>` with: 'um', 'uh', 'er', 'ah', 'like', 'so', 'well', 'you know', 'i mean', 'right'
       - Export `endsWithFiller(text: string): boolean` — check if trimmed lowercase text equals or ends with a space + any filler word

    3. Create `src/detection/heuristics.ts`:
       - Export threshold constants: `PROLONGATION_STALL_MS = 400`, `PROLONGATION_ENERGY_FLOOR = 0.025`
       - Export `detectRepetition(interimText: string): { detected: boolean; confidence: number; repeatCount?: number }`:
         - Split on `[\s\-]+`, filter empty, take last 4 tokens
         - Count consecutive identical trailing tokens (case-insensitive)
         - If repeatCount >= 2: confidence = min(0.92, 0.65 + repeatCount * 0.1), return detected: true with repeatCount
         - Otherwise: detected: false, confidence: 0
       - Export `detectProlongation(energyLevel, interimText, lastInterimText, lastInterimChangeMs, now): { detected: boolean; confidence: number; stallDurationMs?: number }`:
         - stalled = interimText === lastInterimText
         - stallDurationMs = stalled ? now - lastInterimChangeMs : 0
         - hasSpeechEnergy = energyLevel > PROLONGATION_ENERGY_FLOOR
         - If hasSpeechEnergy AND stallDurationMs >= PROLONGATION_STALL_MS: confidence = min(0.85, 0.60 + (stallDurationMs / 1000) * 0.1), return detected: true
         - Otherwise: detected: false, confidence: 0

    4. Create `src/detection/heuristics.test.ts` with tests for ALL behaviors listed above. Use `describe` blocks: 'detectRepetition', 'detectProlongation', 'endsWithFiller'.
